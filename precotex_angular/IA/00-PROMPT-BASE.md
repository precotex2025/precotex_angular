# Reglas de ejecución

Lee el código antes de proponer cambios. No supongas cómo está escrito.

Reutiliza lo que ya existe antes de crear algo nuevo.

Si algo es ambiguo, pregunta. No asumas.

Verifica con `npx tsc --noEmit -p tsconfig.app.json` antes de dar algo por terminado.

Reporta lo que realmente pasó. Si algo falló o quedó pendiente, dilo.

Cambios grandes en fases, cada una compilando por su cuenta.

Trabaja siempre en una rama nueva. El merge lo hace el usuario.
